> 用途：按顺序复制粘贴给 Qoder，一步步把 **M3 简历与作品集**做出来。
> 前置：项目根 `E:\StudyTrack`，`.qoder/rules/00-core.md` 已设 Always Apply。
> 全程**不引入任何外来依赖**（只用白名单里的 `react/react-dom/vite/typescript/tailwindcss/zod/dayjs/idb-keyval`），不做后端、不做登录、不联网取素材。

## 0. M3 到底要做哪些功能（先看清单）

| # | 功能 | 优先级 | 说明 |
|---|---|---|---|
| 1 | 简历工作台 `/resume` | Must | 左侧「经历池」+ 右侧「A4 简历预览」，实时联动 |
| 2 | 勾选经历进简历 | Must | 从经历池勾选/取消；上移/下移排序；「精简为 1 行」开关 |
| 3 | 基本信息编辑 | Must | 姓名/年级/专业/城市/联系方式/求职意向；全部可为空，空的整块不打印 |
| 4 | A4 屏幕预览 | Must | 模拟纸张：A4 比例、页边距 16mm、分页线提示 |
| 5 | 打印导出 PDF | Must | `window.print()` + `@page A4`；打印隐藏全部 UI；超 1 页给提示 |
| 6 | AI 生成简历 bullet | Must | 把一条经历（四段式）转 2–3 条简历句式；**不编造**；每条带原文证据；可单条重生成 |
| 7 | 版本快照 | Should | 每次导出/保存生成快照 v1、v2…，可回看、可恢复 |
| 8 | 作品集页 `/p/:id` | Should | 选 3–6 条精选经历 → 生成可分享页；内容编码进 URL（无后端） |
| 9 | 作品集分享与打印 | Should | 一键复制链接；页面可打印；移动端单栏 |
| 10 | 导出简历 JSON | Should | 复制/下载结构化档案，供 M4 匹配与 MCP 使用 |
| 11 | 空态与引导 | Must | 没有经历 → 引导去 M2 添加；没有姓名 → 顶部提示 |
| 12 | 数据持久化 | Must | 简历状态存 IndexedDB，刷新不丢 |
| 13 | 移动端与可访问性 | Must | 390 宽单栏；键盘可完成勾选与打印；对比度达标 |
| 14 | 不编造校验 | Must | `metrics` 为空时**不显示任何数字**；`confidence: low` 的经历默认不进简历，需用户确认 |

## 2. P1 · 简历工作台骨架（经历池 + 勾选）

```
本轮只做 M3 的工作台页面，不改其他模块。

路由：/resume（左侧常驻导航里已有"简历"入口则接上，没有就加）
布局：桌面两栏 40% / 60%，移动端上下堆叠
- 左栏「经历池」：
  · 列出 IndexedDB 里全部经历，按结束时间倒序
  · 每条显示：类型徽标（课程设计/比赛/科研/实习/作品/志愿）、标题、组织、时间、3 个技能标签

  · 顶部筛选：全部 / 已加入 / 未加入；按类型多选筛选

- 右栏「简历预览」占位：
  · 一个 A4 比例的白纸容器（210:297），里面先显示已勾选的经历条目（纯文本，不做精细排版）
  · 纸容器上方一行状态：已选 N 条

数据：勾选状态存进 IndexedDB 的 resume 对象（selectedExperienceIds: string[]），刷新后保持。
交互：勾选/取消即时更新右侧与"N 条"计数；提供一个「全部清空」按钮（二次确认）。

约束：
- 不新增依赖；数据只读写 src/store/idb.ts；
- 组件拆成 ExperiencePool.tsx 与 ResumePaper.tsx；
- 不编造任何字段，缺字段留空不占位。

验收：勾选 3 条 → 右侧出现 3 条 → 刷新页面仍保持；移动端 390 宽不横向滚动。
完成后输出 3 行：本轮做了什么 / 改了哪些文件 / 下一步建议。
```

## 3. P2 · 基本信息 + A4 排版 + 打印

```
本轮做简历的"能看能打"。

1) 基本信息编辑（右栏顶部，可折叠）：
   姓名、年级（大一~大四/研究生）、专业、城市、手机、邮箱、求职意向；
   全部允许为空；输入即存 IndexedDB；空字段在预览中整行不渲染、不留空行。
2) A4 预览排版（ResumePaper.tsx）：
   - 容器固定 A4 比例，内边距 16mm，正文 10.5pt、行高 1.45，标题层级清晰（姓名 18pt、栏目 12pt 加粗）；
   - 结构顺序：基本信息 → 教育（来自 Profile/基本信息里的专业年级，先简单两行）→ 经历（倒序）→ 技能 → 联系方式；
   - 每段经历：标题行（标题 | 组织 | 时间）+ 2–3 条要点（当前先用 Experience 的 result 与 contribution 拼，AI 改写放下一轮）；
   - 每段经历 break-inside: avoid；栏目之间细分隔线；不显示空栏目。
3) 打印（src/styles/print.css + 按钮）：
   - 右上角「打印 / 存为 PDF」按钮 → window.print()
   - @page { size: A4; margin: 16mm }
   - 打印时隐藏：左侧经历池、导航、按钮、筛选、hover 效果、阴影
   - 打印前检查：若内容估算超过 1 页，弹提示「内容超过一页，建议精简或减少条目」，但允许继续打印
4) 预览与打印必须是同一份 DOM，不要维护两套模板。

约束：不引入 PDF 库；字体用系统中文栈；不上传任何数据。
验收：Chrome 打印预览正好 1 页 A4；字段全为空时打印不出现空标题；移动端预览可折叠。
```

## 4. P3 · AI 生成简历 bullet（不编造）

```
本轮给每段经历加「AI 生成简历要点」。

1) 每段经历在简历里显示 2–3 条要点；未生成时显示按钮「生成要点」，已生成时显示「重新生成」。
2) 走 src/ai/client.ts → 薄代理 → qwen-plus；开发期用 MOCK=1 返回预置结果。
3) Prompt 硬规则（写进 src/ai/tasks/resume.ts）：
   - 只能使用这条 Experience 里已有的 problem/method/contribution/result/metrics/skills；
   - 不得新增公司、数字、奖项、时间、技术栈；
   - metrics 为空时，禁止出现任何百分比、倍数、人数；
   - 每条要点 1 行、动词开头、不超过 40 字；
   - 输出 JSON：{ bullets: [{ text, usedEvidence: string[] }] }，usedEvidence 必须是原文片段。
4) 每条要点下方显示「依据：原文片段」可展开；拿不出依据的要点直接丢弃并在 UI 提示「有 1 条因缺少依据被过滤」。
5) 失败降级：超时/401/MOCK 未配置 → 保留原文（把 result + contribution 拼成两条）并提示「AI 暂不可用，已使用原文」；不阻塞页面。
6) 单条要点可「删掉」「重新生成这一条」。

约束：不新增依赖；不缓存到服务端；不编造；一次性返回（不做流式）。
验收：用 6 条示例经历各生成一次，人工抽查 12 条要点，0 处编造数字；关闭网络后仍能出原文兜底结果。
```

## 5. P4 · 版本快照

```
本轮加"简历版本感"。

1) 每次点击「保存快照」或「打印」前，自动生成一个 ResumeSnapshot：
   { id, version, createdAt, selectedExperienceIds, basics, bulletsSnapshot }
   存 IndexedDB 的独立 key；最多保留 20 个，超出删最旧。
2) 页面顶部「版本」下拉：列出 v1…vN（时间 + 条目数），可「预览」（只读查看当时的简历）与「恢复到此版本」。
3) 恢复时二次确认：「恢复将覆盖当前简历，是否继续？」
4) 首页/简历页顶部显示一句：共 N 个版本，最近一次 2 天前。

约束：不新增依赖；快照只存必要字段，不存图片 base64。
验收：保存 3 个版本 → 切换预览内容正确 → 恢复后当前简历与快照一致 → 刷新后版本仍在。
```

## 6. P5 · 作品集页（可分享、无后端）

```
本轮做作品集分享页。

1) 在简历页加「生成作品集」：从已勾选经历中再精选 3–6 条（多选），选一个封面标题（默认"姓名 · 作品集"）。
2) 生成路由 /p/:id：
   - 内容（标题、精选经历、技能、联系方式）序列化 → 压缩（如 JSON → LZ-string 风格的自实现轻量编码或直接 encodeURIComponent + base64）→ 放进 URL 的 hash；
   - 页面只从这个 hash 读数据，不请求任何接口；数据不存在时显示「链接无效或数据已损坏」+ 返回首页按钮；
   - 不新增依赖：优先用 encodeURIComponent(JSON) + 简单压缩，若体积过大（>8KB）则提示"请减少条目"。
3) 作品集版式：封面（标题 + 一句话 + 姓名/年级）→ 项目卡（标题、时间、四段式精简、证据链接）→ 技能标签 → 页脚（"由学径生成"占位）；
   每张卡片可打印，整页可「复制链接」「打印」。
4) 分享：复制链接按钮 + 提示"任何人打开都能看，内容都在这条链接里，不会上传到服务器"。
5) 打印作品集：同样走 @page A4，打印隐藏按钮。

约束：无后端、无数据库、无上传；不引入二维码库（可后续再加）。
验收：生成链接 → 无痕窗口打开能看到完整作品集 → 断网也能看 → 链接超过 8KB 时有提示。
```

```
本轮只做打磨与验收，不加新功能。

4) 数据安全：设置页或页脚提供「一键清除本机数据」（清空 IndexedDB 并二次确认）。
5) 自检并逐条报告：
   - [ ] vite build 通过
   - [ ] 勾选 → 刷新 → 数据仍在
   - [ ] 打印预览 1 页 A4，按钮/导航隐藏
   - [ ] AI 不可用时走原文兜底，不白屏
   - [ ] 0 处编造数字（用示例经历抽查）
   - [ ] 作品集链接无痕窗口可看
   - [ ] 390 宽无横向滚动
6) 发布到 Qoder Sites，权限「任何人都可访问」，手机 + 无痕窗口各验证一次，给我链接。

约束：不改 M1/M2 逻辑；不新增依赖；不引入 UI 库。
```
