> 用途：不填课表、不填 Key、不导 Excel，只靠落地页「先看示例」写入的数据，把五个面 + 记录官逐条点一遍，用来判断功能有没有坏。
> 站点：`https://studytrack-wjeu32t1uvp.qoder.zone`（建议隐身窗口，保证是干净档案）
> 分工：JD 匹配与「差得多 → 够格」的翻盘演示见 `docs/demo-rag-agent.md`，那份里的分数都是实测值，本清单不重复它的步骤。
> 下面每条预期都来自本机代码与实测，标 **⚠ 日期敏感** 的行隔几天再跑结论会变（示例作业 DDL 和课表周次是写死的日期）。
> 耗时约 15 分钟。任何一步看到空白页、无限 loading、按钮没反应，直接记进第十一节的判定表。

## 一、清库，再进示例

1. 今日页顶部有示例横条，右侧「清除示例并退出」→ 确认「退出演示会清除本机示例数据，继续吗？」，这是最快的复位；也可走灵动岛 → 本机数据备份 → **清除本机数据**（会连同 API-KEY 一起删）
2. 回到落地页，首屏两颗按钮：`开始使用`（走 4 步建档）与 `先看示例`。**点 `先看示例`**
3. 会播一段入场动画，动画结束自动落到「今日」

## 四、征召

- 页头读数：`6 个官方入口 3 个岗位方向`（未粘 JD 时不显示本机岗位库那一段）
- 三张演示卡：腾讯 后台开发实习生 / 字节跳动 数据分析实习生 / 阿里巴巴 算法实习生。**这里不写死分数**——示例战绩里没有 C++、Go、数据结构与算法的竞赛证据，三张卡应当都落在「缺口较大」一侧；把实际读数记进判定表

- 筛选器：关键词搜「性能优化」应命中前端实习那条；搜一个不存在的词给「换个关键词或重置筛选」，不给空白页

## 六、学径空间（留痕星图）

- 清库重进后应当是 **4 颗星**（连续 4 天有绿格），今天那颗最亮（今天有 2 条绿格）
- 点一颗星 → 右侧列出当天留痕；「前一天 / 后一天」可切；空日期给提示不报错
- 「最近点亮」「本机星况」「点亮规则」三块都在；规则文案是「每天只点亮一次」
- 征途的回声以流星出现，攒够成流星雨；**这一页不新增任何数据**，刷新前后星数不变

## 八、数据闭环

1. 灵动岛 → 本机数据备份 → **导出备份**：JSON 里应含课表 / 作业 / 战绩 / 档案 / 简历 / 留痕 / 碎片 / 本机岗位库，**不含 API-KEY**，不含 `Lv.`「品质」「连击」等游戏措辞
2. 刷新页面 → 数据仍在（IndexedDB）
3. **清除本机数据** → 提示「已清除本机全部数据与模型 Key」并回到落地页，五面导航置灰、悬停标题是「XX 完成建档后开启」，直接深链 `#/experiences` 应被拦回建档页
4. **导入备份**（第 1 步那份 JSON）→ 全部还原，星图天数与战绩数与清除前一致
5. 导入一个非备份 JSON 文件 → 提示「文件不是有效的 JSON 请选择学径导出的备份文件」，不白屏

## 九、外观、移动端与打印

- 顶栏「配色」在三套主题之间切：霞光 / 夜间 / 庄园。刷新后记住上一套（`studytrack:landing-theme`）
- 主题光标开关：开启时每套主题自己的箭头 / 手型 / 文本光标；关掉后全部回落系统指针，但焦点环和 hover 反馈不能被一起关掉
- 390 宽：无横向滚动，左侧栏收起，五面导航 / 记录官 / 配色进岛内；触控目标 ≥44px
- 键盘：Tab 能走完留痕 → 记战绩 → 粘贴 JD 三条主路径，焦点环可见（3px 描边）
- 打印（Ctrl+P，简历或作品集页）：A4 一页，导航 / 按钮 / 阴影消失，纸面保持黑白灰，不跟随夜间或庄园的深色底
